# License Header Rule

All C# source files (`.cs`) in this repository MUST include the following 2-line license header at the very top of the file to ensure legal clarity and token efficiency for AI context.

```csharp
// Copyright (c) 2026 PokeLege
// SPDX-License-Identifier: LGPL-2.1-only
```

This header is required for:
- All new files created in the `src/` directory and its subdirectories.
- Any files that are significantly refactored or moved.
